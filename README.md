# 塔塔拼豆工坊 Web 版

纯前端静态网站，无后端接口、Python 或 EXE 依赖。图库、图片量化、手动涂格和擦除均在浏览器执行；用户导入图片不上传。

## 部署

将此目录全部内容上传到静态托管，index.html 放在站点或子目录入口。可以使用 Nginx、Cloudflare Pages 等静态托管；无需构建命令，发布目录就是本目录。JS、JSON、PNG 和模块 Worker 必须通过 HTTP/HTTPS 正常提供，同源路径、正确 MIME 类型即可。支持子目录部署，不需要路由重写。不要直接双击 file:// 页面，浏览器会限制模块 Worker 和 JSON 加载。

开发预览可使用任意静态 HTTP 服务器，例如在本目录执行 python -m http.server 8080。这只是预览方式，正式网站无需 Python。

## 使用

选择塔塔或臭臭，按元素/等阶筛选塔塔，或导入本地图片。生成图纸后，可选择通用色板的 130 种颜色修格，点击“擦除格子”删除错误格子。保存按钮通过浏览器下载 PNG、SVG、CSV 或原图。保存位置由浏览器设置决定，不会写入服务器文件夹；下载未开始时可点击下方重试链接。手机布局已适配。

内置 604 张塔塔完整姿势与 69 张臭臭完整姿势，不展示头像。通用色号不是实体品牌色号。
